# Security Policy

## What this repository is
fazle-ai-red-team-toolkit is an automated red-team and evaluation suite for LLM
applications (prompt injection, PII leakage, jailbreak, bias, adversarial ML,
supply-chain, and rogue-agent test cases). It is built to run against systems the
operator owns or has explicit written authorization to test.

## Authorized Testing Only
Do not run this toolkit against any system you do not own or do not have explicit,
written authorization (Rules of Engagement / Authorization Letter) to test. Running these
tools against third-party systems without authorization may be illegal in your
jurisdiction. The maintainer accepts no liability for misuse.

## Reporting a Vulnerability
If you find a security issue in the toolkit itself, not in a system you tested with it,
email mfrabbi.ai@gmail.com with a description and reproduction steps. Expect an
acknowledgment within 72 hours.

## Responsible Use
This project reduces risk, it does not eliminate it. Findings from this toolkit are not a
guarantee that a target system is secure, and a clean scan is not a certification of any
kind.
